# 7zBot — 智能批量压缩工具

> 基于 PowerShell + 7-Zip 的自动化压缩机器人，内存自适应，放进去就完事了。

## ✨ 特性

- 🧠 **内存自适应** — 自动检测可用内存，智能选择最佳压缩参数（字典大小、线程数、压缩级别）
- 📁 **批量处理** — 一次放入多个文件/文件夹，自动逐个压缩
- 🔄 **文件智能处理** — 压缩包自动解压后重新打包为 `.7z`，文件夹直接打包
- 🚀 **零配置** — 放入 `input`，双击运行，结果在 `output`

## 📋 内存自适应策略

| 可用内存 | 压缩级别 | 字典大小 | 线程数 | 预估内存占用 |
|---------|---------|---------|-------|------------|
| ≥ 16 GB | 极致 | 256 MB | 8 | 23.5 GB |
| ≥ 8 GB | 极限 | 128 MB | 8 | 11.8 GB |
| ≥ 4 GB | 最高 | 64 MB | 4 | 2.9 GB |
| ≥ 2 GB | 标准 | 32 MB | 4 | 1.5 GB |
| ≥ 1 GB | 快速 | 16 MB | 2 | 370 MB |
| < 1 GB | 最快 | 8 MB | 1 | 92 MB |

> 压缩公式：预估内存 ≈ 字典大小 × 10.5 × 线程数

## 🚀 快速开始

### 前置条件

- Windows 10/11
- [7-Zip](https://www.7-zip.org/) 已安装（脚本会自动查找）

### 使用步骤

```
7zBot/
├── 7zBot.ps1      ← 双击运行
├── input/          ← 把要压缩的文件/文件夹放这里
└── output/         ← 压缩结果自动输出到这里
```

1. 将文件或文件夹放入 `input` 目录
2. 双击运行 `7zBot.ps1`
3. 等待处理完成，在 `output` 目录查看结果

### 输出格式

- 所有输出均为 `.7z` 格式
- 使用 LZMA2 算法，压缩级别 `mx=9`（最高）
- 启用固实压缩（`-ms=on`），提升压缩率

## ⚙️ 压缩参数

脚本使用以下核心参数：

```powershell
-t7z                    # 7z 格式
-m0=lzma2               # LZMA2 算法
-mx=9                   # 最高压缩级别
-mfb=<fast bytes>       # 快速字节（根据内存自适应）
-md=<dictionary>        # 字典大小（根据内存自适应）
-ms=on                  # 固实压缩
-mmt=<threads>          # 多线程（根据内存自适应）
```

## ❓ 常见问题

**Q: 运行时提示"未找到 7-Zip"？**  
A: 请先安装 [7-Zip](https://www.7-zip.org/)，安装后重新运行脚本即可。

**Q: input 目录为空会怎样？**  
A: 脚本会提示错误并退出，请确保 input 目录中至少有一个文件或文件夹。

**Q: 支持哪些输入格式？**  
A: 任何 7-Zip 支持的格式（zip、rar、tar、gz 等），脚本会先解压再重新打包为 `.7z`。
